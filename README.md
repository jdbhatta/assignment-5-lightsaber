# assignment-5-lightsaber

Name: Jay Bhatta
Project Name: LightSaber in a room

Demo Video Link: https://youtu.be/N5_FMyKiLZg

How to run: Open the project and within my saved scene press Play and make sure you are inside the Game view or else you
will be looking at a box from the outside. 

Controls: Space = on/off; 1 = blue; 2 = green; 3 = red.

Extensions: power-on/off sounds, switchable colors, and matching room lighting that fades with blade extension.

Outside resources:
- Downloaded the free light saber sound from this website https://pixabay.com/sound-effects/search/lightsaber/
- Also used this for audio (from the assignment tutorial doc) https://docs.unity3d.com/2022.3/Documentation/ScriptReference/AudioSource-clip.html
